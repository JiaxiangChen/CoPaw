## Why

测试分行白名单用户需要在财富工作台为不同分行的客户经理代建并分发规划，同时保持所有正常用户及普通模式的原有逻辑。

## What Changes

- 仅真实登录分行 V00001、用户编号 80008888 显示默认关闭的运维模式开关；配置支持追加用户。
- 头部显示时提供分行选择，读取 BBK_ID_MAP 并排除总行 100；hideLogo=true 不提供运维入口。
- 运维模式使用独立的工作台上下文，选择目标分行后以分行中台角色复用规划和分发流程，真实操作人不变。
- 切换时隔离草稿、列表、场景、分发人员和异步请求；仅管理本人代建的规划，继续尊重服务端 editable。
- 仅实施前端，记录外部 Java 服务需确认的跨分行授权、机构参数及本人规划权限契约。

## Capabilities

### New Capabilities

- `wealth-operations-mode`: 财富工作台白名单用户的跨分行中台代建模式。

### Modified Capabilities

无。关闭运维模式时保持现有工作台行为及接口契约。

## Impact

仅 console/src/pages/WealthWorkbench、相关前端配置/测试与对接说明。读取现有 BBK_ID_MAP，不修改其省略的机构数据；不修改共享登录态、Python 后端或 Java 服务。前端白名单仅控制界面，Java 授权由服务端团队确认。

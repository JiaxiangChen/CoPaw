# 定时任务追踪 UI Demo

独立、可交互的前端原型，供确认页面展示；没有真实接口、权限校验或调度操作，不接入 Console 生产路由。

## 范围与布局

- 管理员在来源范围内输入一个新版任务 ID，查看当前属性和单任务时间轴。
- 父任务/子任务只标注身份，不展示关联任务列表。
- 时间轴混合管理、调度、执行、通知记录，按实际记录时间筛选；计划调度时间单独显示。
- 管理记录仅显示已有提交信息、当前结果及更新时间；通知失败时刻未知时作为附注，不制造事件。
- 提供演示任务切换、时间范围、事件分类、顺序切换、展开详情、未知 ID 与空范围状态。

## 实施与校验

1. 先准备浏览器交互断言，确认未实现时缺少页面入口。
2. 使用 `index.html`、`demo.css`、`demo.js` 实现，不安装依赖、不改后端或生产页面。
3. 浏览器检查查询、筛选、展开、排序、空状态及 1440/1280/768 宽度；保存截图。
4. 顺序自检，并打开预览交由用户确认；不提交、不推送。

可直接在浏览器打开 `index.html`，或在本目录启动静态 HTTP 服务。
